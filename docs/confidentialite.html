Règles de confidentialité

Dernière mise à jour : 27 octobre 2026

En bref : MuscuApp n'a pas de serveur. Vos données restent sur votre téléphone et, si vous activez la synchronisation, dans le dossier caché réservé à l'application dans votre Google Drive. Elles ne sont ni vendues, ni partagées, ni utilisées pour de la publicité ou des statistiques.

Les données de l'application

MuscuApp enregistre ce que vous y notez : vos exercices et vos séances, vos pesées, votre plan alimentaire, les repas cochés, votre liste de courses et vos réglages. Ces données sont gardées dans l'espace privé de l'application sur votre téléphone. Si la sauvegarde automatique d'Android est activée sur votre téléphone, Android peut aussi les sauvegarder dans votre compte Google, comme pour les autres applications.

Les données de votre compte Google

La synchronisation est facultative. Elle ne démarre que si vous connectez votre compte Google dans les réglages de l'application. MuscuApp demande alors un seul accès :

  • https://www.googleapis.com/auth/drive.appdata : voir, créer et supprimer ses propres données de configuration dans votre Google Drive.

Cet accès est limité au dossier caché réservé à MuscuApp dans votre Google Drive : l'application ne peut ni voir, ni modifier vos fichiers et dossiers. Avec cet accès :

  • MuscuApp écrit dans ce dossier un seul fichier, qui contient vos données de l'application, le numéro de version de l'application et le nom de l'appareil qui l'a envoyé (pour vous dire d'où vient le dernier envoi).
  • MuscuApp lit ce même fichier pour retrouver vos données sur vos autres appareils.
  • MuscuApp lit l'adresse e-mail de votre compte Google pour l'afficher dans les réglages et toujours utiliser le même compte. Elle n'est gardée que sur votre téléphone.

Ces données ne servent qu'à garder les mêmes données sur vos appareils. Elles passent directement de votre téléphone à Google Drive, par une connexion chiffrée (HTTPS), sans passer par un autre serveur. Elles ne sont transmises à personne.

L'utilisation et le transfert vers toute autre application des informations reçues des API Google par MuscuApp respectent le Règlement sur les données des utilisateurs des services d'API Google, y compris les exigences d'utilisation limitée.

Supprimer vos données

  • Arrêter la synchronisation : dans MuscuApp, Réglages → Synchronisation → Déconnecter.
  • Supprimer la copie gardée dans Google Drive : dans Google Drive, Paramètres → Gérer les applications → MuscuApp → Options → Supprimer les données d'application masquées.
  • Retirer l'accès de MuscuApp à votre compte : sur la page Applications et services tiers de votre compte Google.
  • Supprimer les données du téléphone : désinstallez l'application, ou effacez ses données dans les paramètres d'Android.
