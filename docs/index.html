MuscuApp

Une application Android pour suivre ses séances de musculation semaine après semaine, son plan alimentaire et son poids.

Télécharger l'application

Ce que fait l'application

  • Séances : les exercices, les séries, les répétitions et les charges de chaque semaine, avec la progression d'une semaine à l'autre.
  • Nutrition : le plan alimentaire jour par jour, les repas à cocher, l'eau, et la liste de courses de la semaine.
  • Poids : les pesées et leur courbe, pour suivre une prise de masse.
  • Repos : un minuteur entre les séries, qui sonne même écran éteint.

Vos données

Vos données restent sur votre téléphone. Si vous activez la synchronisation avec votre compte Google, une copie est gardée dans le dossier caché réservé à MuscuApp dans votre Google Drive, pour retrouver les mêmes données sur tous vos appareils.

L'application n'a accès qu'à ce dossier, pas à vos fichiers, et n'envoie vos données nulle part ailleurs. Le détail est dans les règles de confidentialité.
